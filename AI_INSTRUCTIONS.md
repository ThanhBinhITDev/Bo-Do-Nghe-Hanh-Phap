# QUY TẮC DÀNH CHO AI (AGENT INSTRUCTIONS)

Tự động lưu tool/script pentest mới vào ổ cứng: `/Volumes/Thanh Binh /Bộ đồ nghề hành pháp`

Theo đúng 7 thư mục chuẩn:
1. `recon/`     : nmap, subdomain, port scan, OSINT
2. `web/`       : sqlmap, nuclei, ffuf, xss, web fuzzing
3. `exploit/`   : exploit frameworks, router, IoT
4. `passwords/` : SecLists, wordlists, brute-force, hashcat
5. `sniff/`     : bettercap, mitmproxy, traffic redirect
6. `privesc/`   : PEASS-ng, payloads, impacket, leo quyền
7. `wifi/`      : aircrack-ng, wifi hacking

Cập nhật README.md & launch_toolkit.sh sau khi thêm tool.
